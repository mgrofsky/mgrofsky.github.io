Safety & security tools

Boundary Lab

Redline checks chatbot answers. Dye traces tool-call values to source text. Latch controls whether calls can run.

Outcome: Released reusable tools to check answers, trace copied values, and control AI actions.

Explore the codeDye guideLatch guide
How it works

Redline

Tests chatbot answers against written rules and reports missed problems and false alarms.

Dye

Matches tool-call values to marked source text, such as tickets, emails, and web pages. These matches help an app review copied values; they do not detect every form of prompt injection.

Latch

Checks permissions, approvals, and action limits before a tool call runs. It can also use Dye's report to block calls that act on copied values.
